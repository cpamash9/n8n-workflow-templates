1. **001-save-gmail-attachments-to-google-drive.json** — every attachment on a matching Gmail message lands in a Google Drive folder automatically. Great for invoices and receipts.

## How to import

Download a JSON file, then in n8n go to Workflows → Import from File and pick the file. You will need to connect your own Gmail / Google Drive / Google Sheets credentials — the workflows do not include anyone else's keys.
